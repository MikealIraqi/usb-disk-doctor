# usb-disk-doctor

أداة عراقية لفحص وتشخيص وإصلاح فلاشات USB والهاردات الخارجية. بالعربية وبدون إنترنت.

🩺 UsbDiskDoctor — طبيب الفلاشات وأقراص USB

UsbDiskDoctor


أداة عراقية تعمل على Windows، تفحص وتشخّص وتُصلح وحدات التخزين الخارجية (فلاشات USB، هاردات، SD) — بدون إنترنت، بالعربية، وبواجهة حديثة.


ماذا يفعل البرنامج؟

1️⃣ يكتشف ويفحص الأجهزة

يكتشف أجهزتك تلقائياً ويعرض تفاصيلها الكاملة (الاسم، الحجم، الرقم التسلسلي، الحالة). ثم يقرأ بيانات S.M.A.R.T.، ويفحص نظام الملفات، ويعطيك تقييم واضح: سليم ✅ / تحذير ⚠️ / حرج 🔴.

2️⃣ يكشف الفلاشات المزيفة 🎯

الميزة الأقوى — كثير فلاشات تعلن 128 GB وهي فعلياً 8 GB. البرنامج يكتب أنماط اختبار على كامل السعة، يقرأها، واكتشف أي wraparound — ثم يعطيك السعة الحقيقية بدقة.

3️⃣ يستعيد الملفات ويقترح إصلاحات آمنة

يسترجع ملفاتك المفقودة (صور JPEG/PNG، PDF) بتقنية File Carving — بدون الإضرار بالبيانات الأصلية. 
ثم يقدّم قائمة إصلاحات مصنّفة (آمن / متوسط / خطير)، وكل إجراء لازم يمر على نافذة تأكيد قبل التنفيذ.


ما يميّزه
🛡️ آمن بالتصميم: لا يكتب إلا بإذنك، قائمة بيضاء للأوامر، منع الكتابة على القرص المصدر


📄 تقارير احترافية: HTML عربي (RTL) + JSON — للمشاركة مع مختص أو للأرشيف


📚 قاعدة معرفة عربية: 9 مقالات تشرح SMART، RAW، الفلاشات المزيفة، ومتى تروح لمختص
